# Evergarden

Evergarden is a responsive static eCommerce website created for a gardening and landscaping business. This project was developed as part of a course to demonstrate proficiency in front-end web development technologies.

> Live Site: https://ruzzell-o.github.io/Evergarden/

## Features

- **Home Page:** A welcoming introduction to Evergarden with highlighted sections for products, services, and contact information.
- **Products Page:** A comprehensive catalog of gardening products available for purchase, including:
    - Plants (e.g., Aloe Vera, Cactus, Monstera)
    - Gardening Tools (e.g., Shovels, Rakes, Hoses)
    - Soil and Fertilizers
    - Pots and Plant Boxes
    - Seeds
    - Gardening Wears
- **Services Page:** Information on the gardening and landscaping services provided by Evergarden.
- **About Page:** The story and mission of the Evergarden company.
- **Contact Page:** A form for users to get in touch with the business.
- **Responsive Design:** The website is fully responsive and accessible on various devices, including desktops, tablets, and mobile phones.

## Technologies Used

- **HTML5:** For the structure and content of the web pages.
- **CSS3:** For styling and layout, including the use of parallax effects.
- **JavaScript:** For interactive elements and dynamic features.
